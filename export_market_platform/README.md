# 出口市场趋势与机会诊断平台（原型）

## 1. 需要准备
- Windows 电脑
- Python 3.11 或 3.12（安装时勾选 `Add Python to PATH`）
- 海关导出的 CSV / XLSX 文件

## 2. 安装与运行
1. 解压项目文件夹。
2. 在项目文件夹空白处点击地址栏，输入 `cmd` 并回车。
3. 在命令行依次执行：

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

4. 浏览器打开后，在左侧上传海关原始文件。

如果 `python` 命令不可用，可尝试 `py` 替代 `python`。若安装 Python 时未勾选 PATH，需要重新运行安装程序并启用 PATH。

## 3. 数据格式
默认识别以下列名（必须完全对应）：
- 数据年月（例如 `202501`）
- 商品编码（例如 `85`）
- 商品名称
- 贸易伙伴编码
- 贸易伙伴名
- 人民币

金额列应可转换为数值。程序会尝试读取常见 CSV 编码；Excel 文件可直接上传。

## 4. 当前功能
- 月度出口额趋势
- 目的地出口额排名、市场份额、累计份额
- 目的地月度变化对比
- 市场集中度 HHI
- 数据质量检查与 CSV 汇总下载

## 5. 重要口径提醒
- 请先确认源文件是否含有“合计/总计/世界/全球”等汇总行，避免重复计算。程序提供疑似汇总行排除选项，但需根据原始统计口径判断。
- 重复的“月份 + 商品编码 + 贸易伙伴编码 + 贸易伙伴名”可能是重复记录，也可能是可加总的拆分项，必须核验。
- 只有 2025 年 12 个月时，适合做描述性市场分析和初步趋势展示，不足以可靠评估季节性预测能力。预测模块应在补充多年月度数据后再加入。
- HHI 是描述性集中度指标，不应单独作为市场风险结论。
- 当前 AI 解读模块尚未接入大模型 API；先确保统计结果正确，再接入 AI。
