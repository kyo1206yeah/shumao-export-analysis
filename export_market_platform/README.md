# 数贸罗盘——基于海关统计数据的商品出口市场分析与决策辅助平台

## 项目简介

**数贸罗盘**是一款面向海关进出口商品统计数据的可视化分析与决策辅助平台。平台支持导入从海关统计平台下载的商品贸易数据，通过数据处理、统计分析、可视化展示和模型预测，帮助用户了解商品出口趋势、识别不同贸易伙伴市场的变化特征，并为出口市场分析提供参考。

平台适用于海关统计平台导出的**不同商品类别和商品编码数据**，不局限于某一特定商品。本项目开发与功能演示主要以第85类商品（电机、电气设备及其零件等）的出口数据为例。

## 主要功能

- **数据导入与处理**：支持 CSV、Excel 格式数据导入，可进行多文件合并、数据清洗、时间筛选和商品筛选，为后续分析提供数据基础。
- **出口趋势分析**：从总体规模、月度变化和时间趋势等角度展示商品出口情况，辅助观察出口规模及其变化特征。
- **贸易伙伴市场分析**：分析不同贸易伙伴的出口规模、市场份额和市场集中程度，了解出口市场结构。
- **市场机会与风险诊断**：结合市场规模、增长变化、份额和月度波动等指标，对不同贸易伙伴市场进行比较和分类，辅助识别潜在机会与风险。
- **出口趋势预测**：采用季节性朴素预测和 Holt-Winters 指数平滑模型进行时间序列预测，并通过历史留出数据对模型表现进行评估，为未来趋势判断提供参考。
- **AI 辅助市场分析**：接入 DeepSeek API，基于平台计算得到的统计指标生成市场分析文本，辅助解释数据变化及其可能反映的市场特征。
- **数据质量检查**：检查数据中的异常月份、金额转换问题、空缺贸易伙伴信息、疑似汇总记录及重复业务键等情况，帮助用户了解数据质量。
- **综合分析报告**：整合主要分析结果与图表，支持生成 HTML 格式的综合报告，便于查看、保存和分享。

## 技术实现

| 技术 | 主要用途 |
|---|---|
| Python | 数据处理与分析 |
| Streamlit | 交互式平台开发 |
| Pandas、NumPy | 数据清洗、统计计算 |
| Plotly | 交互式数据可视化 |
| Statsmodels | 时间序列预测 |
| DeepSeek API | AI 辅助分析与文本生成 |

平台采用“**数据处理—统计分析—可视化诊断—预测分析—AI 辅助解读**”的整体思路，将传统数据分析方法与大语言模型相结合。

## 运行方式

### 运行环境

- Windows 系统
- Python 3.11 或 3.12
- 海关统计平台导出的 CSV 或 Excel 数据文件

### 安装依赖并启动

克隆或下载本项目后，在项目目录下打开终端，依次执行：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

启动后，根据终端提示在浏览器中打开平台页面。

### AI 功能配置

AI 辅助分析功能需要配置 DeepSeek API Key。未配置 API Key 时，平台的数据处理、统计分析、可视化和预测等其他功能仍可使用。

本地可在项目目录下创建 `.streamlit/secrets.toml` 文件，并添加：

```toml
DEEPSEEK_API_KEY = "your_api_key"
```

请勿将包含真实 API Key 的配置文件上传至公开仓库。

## 数据说明

平台的数据输入为从海关统计平台下载的商品贸易统计数据。不同商品可根据实际下载的数据选择相应的商品编码或商品名称进行分析。

数据需要包含平台分析所需的基本字段，主要包括：

- 数据年月
- 商品编码
- 商品名称
- 贸易伙伴编码
- 贸易伙伴名称
- 人民币金额

具体字段名称及数据格式应与平台的数据读取和处理要求保持一致。

## 使用说明与注意事项

1. **商品适用范围**：平台并非专门针对第85类商品开发。只要导入的数据符合平台所需字段和格式要求，即可用于其他商品类别的出口分析。
2. **数据口径**：分析结果取决于原始数据的统计口径、时间范围和数据完整性。导入前建议核对数据来源及字段含义。
3. **数据质量**：平台提供的质量检查用于辅助发现潜在问题，不会自动保证所有原始数据均准确无误。对于疑似汇总记录和重复业务键，应结合原始数据核实。
4. **市场诊断**：市场增长、规模、份额和波动等指标反映的是历史统计特征，不能直接等同于未来市场潜力或实际商业机会。
5. **趋势预测**：预测结果依赖历史数据及模型假设，可能受到突发事件、政策变化和市场环境变化等因素影响，不构成对未来出口表现的保证。
6. **AI 分析**：AI 生成的内容主要用于辅助解释统计结果，仍需结合原始数据和实际贸易背景进行判断，不应替代专业分析。

## 项目定位

本项目旨在探索海关统计数据在出口市场分析中的应用，通过交互式数据分析、市场诊断、时间序列预测与 AI 辅助解读，降低数据整理和市场分析的操作门槛，为商品出口市场研究提供一个可扩展的分析工具。
